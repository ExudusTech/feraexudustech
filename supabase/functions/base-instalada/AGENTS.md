# base-instalada rules
- Device stock is products.stock, changed only through mov_estoque: the comodato_estoque trigger takes devices out on ATIVO/EM_TESTE/RETIRADO and puts them back on any other status or deletion, ajustar_estoque is the manager-only manual path, and direct product edits are logged; so every balance change lands in stock_movements with author and reason.
- Reservations are computed, never stored (_shared/estoque.ts): open visits from today with device items minus devices installed in that occurrence (comodatos.ocorrencia_schedule_id), plus open replacement orders not tied to a counted visit; SEPARADO devices are part of a reservation, never added on top.
- QR labels: comodatos.etiqueta_numero (unique per organization, immutable by trigger) is the device identity; numbers are linked only by scanning (etiqueta_* actions here, caller access checked first), points with quantity > 1 are split with comodato_separar_unidade so one label = one device, and device events are schedule_evidencias tipo 'evento'.
- The public /q/<n> path calls etiqueta-publica, which returns only a wa.me link (establishment named only for an active device, under a per-IP hourly limit), so no internal data is exposed.
