# visita-acoes rules
- Off-site check-in is allowed only for commercial visits (permiteCheckinForaDoLocal in _shared/visit-exec.ts); every other type is refused server-side for every role and alerts managers, and every evaluated point carries a photo (avaliacaoErro), so field records are verifiable.
- Without app GPS, check-in still opens the visit with schedules.aguardando_localizacao; check-out is refused while it is set, and only mcp registrar_localizacao_checkin clears it (on-site, destination without coordinates, or off-site commercial) on the user's open waiting visit (cited #OC, else most recent), so no distance/time guessing decides which visit a WhatsApp location belongs to.
